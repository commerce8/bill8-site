# Bill8:Reporting — the reporting surface

Report types that define a query shape, report runs that execute
them, and scheduled reports that deliver output files via platform
storage — the merchant's analytics window into their money.

## Use cases

- **Report types** — payments, settlements, subscriptions, disputes —
  each a defined query shape over the vertical's own data.
- **Report runs** — execute on demand or on the declared schedule;
  output lands as files in Sentin8:Storage for pickup.
- **Scheduled delivery** — recurring reports ride the platform's
  declarative schedule registration (Sentin8:Cron proxy-back).
